В этом репозитории лежат файлы-приложения к курсовой, посвященной измерению эффективности использования LLM для задачи GEC.

Картинки "Elbow method" иллюстрируют выбор гипперпараметра k для кластеризации.

Файлы, содержащие "metrics" в названии - файлы, где каждой ошибке присвоен кластер, полученный в результате кластеризации, и метрики.

Файл "total_mistakes_df" содержит рабочий файл с размеченными вариантами исправлений.

В файле "Multiple gold corrections (Responses)" можно ознакомиться с результатами опроса, направленного на выявление дополнительных золотых исправлений.
